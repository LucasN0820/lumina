# 0016 — polish

> 模块：polish ｜ 优先级：16 ｜ 依赖：多（0005,0006,0009 等） ｜ 里程碑：M5 对应 SPEC：「M5 打磨」

## 目标

体验与稳健性打磨：草稿/高清两档出图、预设分类筛选、收藏、统一空/错/加载态、限流与失败重试。

## 范围

- In：两档出图、分类筛选、收藏（喜欢）、错误/空/骨架态、客户端与服务端限流与重试。
- Out：合规相关（本期不做）。

## 涉及文件

- 后端：`generate` 支持
  `quality: draft|hd`（draft 用更快/更便宜档，hd 出 2K+）；简单限流中间件；失败重试策略。
- 前端：`apps/mobile/src/features/create/`（两档切换、骨架态）、`apps/mobile/src/features/library/`（收藏、分类筛选）、统一
  `EmptyState/ErrorState/Skeleton` 组件。
- 数据：`Wallpaper` 可加 `favorite` 字段（迁移，沿用 0002 命名约定 `@map`）。

## 实现要点

- 两档：draft 快出（低分辨率/turbo 档）用于迭代预览，确认后 hd 出全分辨率；UI 明确区分。
- 限流：同设备/用户出图频控，避免刷量与成本失控。
- 重试：provider 失败做有限次退避重试；最终失败给清晰提示。
- 收藏/筛选：库 Tab 支持按分类与「已收藏」过滤。
- 若新增字段，迁移须遵守 0002 约定（snake_case `@map` + `created_at/updated_at`）。

## 独立测试

- 切 draft/hd 观察速度与清晰度差异。
- 快速连点出图触发限流提示。
- 断网/超时触发重试与错误态。
- 收藏一张图后在库 Tab 用「已收藏」筛出。

## 完成标准 (DoD)

- [x] 草稿/高清两档可切换且行为正确。
- [x] 限流与失败重试生效。
- [x] 空/错/加载态统一且友好。
- [x] 收藏与分类筛选可用。
